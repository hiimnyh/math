---

## Methodology & Workflow

Rather than traditional notes, I try to built around Active-Recall Concept Checklists. 

1. **Markdown First:** While covering a topic or course, I draft bullet points formatted as core questions, definitions, and theorems that I need to be able to state and prove from memory.
2. **LLM Polish to LaTeX:** Once a module's markdown checklist is complete, I ask LLMs to format and compile the raw Markdown into LaTeX files.
